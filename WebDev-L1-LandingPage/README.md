# Wanderly - Explore Beyond

## About the Project
Wanderly is a responsive travel landing page designed to inspire users to explore beautiful destinations and discover new adventures.

## Features
- Responsive navigation bar
- Attractive hero section with background image
- Call-to-action button
- Destination cards
- About and feature section
- Responsive design for mobile and desktop
- Clean and modern user interface

## Technologies Used
- HTML5
- CSS3
